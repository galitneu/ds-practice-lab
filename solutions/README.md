# פתרונות ייחוס למורה

אין לפתוח תיקייה זו בזמן תרגול אלא אם גלית ביקשה במפורש פתרון או בדיקת פתרונות. הקבצים `exNN.py` הם פתרונות לחוזי הקוד; המחברות `NN_reference.ipynb` מדגימות גם חקירה, גרפים והשוואות. אין להעתיק אותן אל `src/` בלי בקשה מפורשת.

להרצה ושמירת פלט המחברות: `USE_SOLUTIONS=1 .venv/bin/python scripts/validate_references.py`.

להרצת בדיקות הייחוס: `USE_SOLUTIONS=1 make test`. הדיון המחקרי אינו בעל תשובה יחידה; העריכי אותו לפי המחוון והפלט שהורץ. מחברות הייחוס נשמרו עם פלט מהרצה כדי לאפשר בדיקה של הדוגמאות.
